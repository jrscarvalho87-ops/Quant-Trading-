# Quant Trading — Academia de investigação quantitativa

Plataforma educativa em português de Portugal, construída aula a aula. Começamos do zero: mercados, matemática, estatística, programação, econometria e machine learning.

## Conteúdos
- [Aula 01 — O que é quantitative trading?](aulas/01-introducao.md)
- [Plano curricular](docs/plano-curricular.md)
- [Fontes e metodologia editorial](docs/fontes.md)

## Aplicação
Site estático em `public/`, sem dependências. Para publicar no Render: Static Site, build command `echo ready`, publish directory `public`.

## Princípios
Pesquisa e educação, sem sinais de negociação ou promessas de rentabilidade. Explicações originais, fontes identificadas e exercícios verificáveis.
